This archive contains the final form of the prototype for the Adaptive AI Opponent capstone project. The version within in is a prototype that displays navigation, radar build and avoidance behaviour.

The C++ AIs that the agent was trained against are contained in the C++ Base Game Opponents folder both in their raw modifiable form and the final compiled versions I utilized.

The maps that the agent was run on for final scenario testing and training are included in the Maps folder in their ready to use format. If they stop working at some point in the future, the file type is a renamed zip so the images can be extracted from it.
